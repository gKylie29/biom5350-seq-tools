# biom5350-seq-tools

## Purpose
The purpose of this repository is to give information about FASTA files. 

## Usage
Run the script by entering the following command into the terminal: python gc_content.py example.fasta

## Output
The script outputs the GC content, AT content, and length of each sequence as well as the average GC content among all sequences
